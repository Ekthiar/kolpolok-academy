# কল্পলোক একাডেমি — কোচিং সেন্টার ম্যানেজমেন্ট সিস্টেম

Django দিয়ে তৈরি সম্পূর্ণ ফাংশনাল কোচিং সেন্টার ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন। এতে তিনটি ব্যবহারকারী ধরন (রোল) রয়েছে: **Admin**, **Teacher (শিক্ষক)** এবং **Student (শিক্ষার্থী)**।

## ফিচারসমূহ

### শিক্ষার্থী (Student)
- লগইন করে নিজস্ব ড্যাশবোর্ড দেখা
- সাপ্তাহিক/মাসিক/মডেল টেস্ট/বার্ষিক পরীক্ষার ফলাফল দেখা (নম্বর, শতকরা হার, গ্রেড)
- মাসিক বেতনের অবস্থা দেখা (বকেয়া/পরিশোধিত/আংশিক)
- ক্লাস রুটিন দেখা (নিজ শ্রেণির)
- নিজের উপস্থিতির হিসাব দেখা
- নোটিশ বোর্ড দেখা
- প্রোফাইল সম্পাদনা ও পাসওয়ার্ড পরিবর্তন

### শিক্ষক (Teacher)
- নিজের ক্লাস রুটিন দেখা
- নতুন পরীক্ষা তৈরি করা এবং শ্রেণিভিত্তিক ফলাফল একসাথে যুক্ত/সম্পাদনা করা
- শ্রেণিভিত্তিক দৈনিক উপস্থিতি নেওয়া
- নোটিশ প্রকাশ করা
- প্রোফাইল সম্পাদনা

### অ্যাডমিন (Admin)
- শিক্ষক ও শিক্ষার্থী যুক্ত/সম্পাদনা/মুছে ফেলা
- শ্রেণি ও বিষয় ব্যবস্থাপনা
- ক্লাস রুটিন তৈরি ও শিক্ষকদের রুটিন নির্ধারণ
- মাসিক বেতনের তালিকা (bulk) তৈরি ও পরিশোধ হালনাগাদ করা
- পরীক্ষা মুছে ফেলা, নোটিশ পরিচালনা
- ড্যাশবোর্ডে সার্বিক পরিসংখ্যান (মোট শিক্ষার্থী/শিক্ষক/আদায়কৃত বেতন ইত্যাদি)
- Django Admin প্যানেল (`/django-admin/`) থেকেও সম্পূর্ণ ডেটা ব্যবস্থাপনা করা যাবে

## প্রযুক্তি
- Python 3.12+, Django 6.1
- SQLite (ডিফল্ট; প্রোডাকশনে PostgreSQL/MySQL এ পরিবর্তন করা যাবে)
- Bootstrap 5 (CDN থেকে) + বাংলা ফন্ট (Hind Siliguri)

## ইনস্টলেশন

```bash
# ১. ভার্চুয়াল এনভায়রনমেন্ট তৈরি করুন
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

# ২. প্রয়োজনীয় প্যাকেজ ইনস্টল করুন
pip install -r requirements.txt

# ৩. মাইগ্রেশন চালান
python manage.py migrate

# ৪. নমুনা ডেটা তৈরি করুন (ঐচ্ছিক কিন্তু সুপারিশকৃত — টেস্টের জন্য)
python manage.py seed_demo_data

# ৫. সার্ভার চালু করুন
python manage.py runserver
```

এরপর ব্রাউজারে যান: http://127.0.0.1:8000/

## ডেমো লগইন তথ্য (seed_demo_data চালানোর পর)

| রোল      | ইউজারনেম     | পাসওয়ার্ড       |
|----------|--------------|------------------|
| Admin    | `admin`      | `admin12345`     |
| Teacher  | `rahim_sir`  | `teacher12345`   |
| Student  | `student1`   | `student12345`   |

> **নিরাপত্তা সতর্কতা:** প্রোডাকশনে ব্যবহারের আগে অবশ্যই এই ডেমো পাসওয়ার্ডগুলো পরিবর্তন করুন এবং `seed_demo_data` কমান্ডটি প্রোডাকশন ডেটাবেজে না চালানোই ভালো (এটি শুধু টেস্টিং/ডেমোর জন্য)।

নিজে আলাদাভাবে সুপারইউজার তৈরি করতে চাইলে:
```bash
python manage.py createsuperuser
```
(এরপর Django Admin থেকে ম্যানুয়ালি `role = ADMIN` সেট করে দিন, অথবা শেলে গিয়ে `user.role = 'ADMIN'; user.save()`)

## প্রোডাকশনে নেওয়ার আগে যা করণীয়
1. `config/settings.py` তে `SECRET_KEY` পরিবর্তন করুন এবং এটি এনভায়রনমেন্ট ভ্যারিয়েবল থেকে নিন।
2. `DEBUG = False` করুন এবং `ALLOWED_HOSTS` এ আপনার ডোমেইন যুক্ত করুন।
3. SQLite এর পরিবর্তে PostgreSQL/MySQL ব্যবহার করুন (বড় পরিসরে)।
4. `python manage.py collectstatic` চালিয়ে স্ট্যাটিক ফাইল প্রস্তুত করুন এবং Nginx/Apache দিয়ে সার্ভ করুন, অথবা Gunicorn/uWSGI দিয়ে অ্যাপ চালান।
5. HTTPS (SSL) নিশ্চিত করুন।

## প্রজেক্ট কাঠামো
```
kolpolok_academy/
├── config/            # প্রজেক্ট সেটিংস, urls
├── accounts/          # User মডেল (Admin/Teacher/Student), প্রোফাইল, লগইন-লগআউট
├── academy/           # ক্লাস, বিষয়, রুটিন, পরীক্ষা, ফলাফল, বেতন, উপস্থিতি, নোটিশ
│   └── management/commands/seed_demo_data.py   # নমুনা ডেটা তৈরির কমান্ড
├── templates/         # সব HTML টেমপ্লেট (Bootstrap 5 ভিত্তিক)
├── static/            # কাস্টম CSS/JS (থাকলে)
├── media/             # আপলোডকৃত প্রোফাইল ছবি
├── manage.py
└── requirements.txt
```

## নতুন কিছু যুক্ত করতে চাইলে
- নতুন মডেল/ফিচার যুক্ত করার পর `python manage.py makemigrations` ও `python manage.py migrate` চালাতে ভুলবেন না।
- সব রোল-ভিত্তিক এক্সেস কন্ট্রোল `accounts/decorators.py` তে (`admin_required`, `teacher_required`, `student_required`) — নতুন ভিউ তৈরির সময় প্রয়োজন অনুযায়ী ব্যবহার করুন।

কোনো প্রশ্ন বা কাস্টমাইজেশনের প্রয়োজন হলে জানাবেন — নতুন ফিচার (যেমন SMS নোটিফিকেশন, অনলাইন পেমেন্ট গেটওয়ে, রিপোর্ট কার্ড PDF এক্সপোর্ট) যোগ করা যাবে।
